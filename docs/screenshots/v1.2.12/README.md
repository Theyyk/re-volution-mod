# Скриншоты v1.2.12

Актуальный набор снимков Test для релиза v1.2.12. Исторические изображения прошлых версий остаются отдельно в `docs/archive/screenshots/`.

Ожидаемые файлы релизного набора:

- `gui-v1.2.12-full.png` — основной GUI: статистика, валюта, ресурсы, персонаж и коллекция рун.
- `gui-v1.2.12-rune-tooltip.png` — tooltip прокачанной руны с рангом, усилением и эффектами.
- `gui-v1.2.12-enhancement-purchase.png` — массовое усиление и зелёная визуальная обратная связь.
- `gui-v1.2.12-admin-mob-creation.png` — Admin / Test Panel, вкладка создания managed-моба.
- `gui-v1.2.12-number-simplified.png` — режим больших чисел `Упрощенный`.
- `gui-v1.2.12-number-full.png` — режим больших чисел `Полный`.
- `gui-v1.2.12-number-engineering.png` — режим больших чисел `Инженерный`.

Перед merge release-ветки PNG добавляются из принятого runtime-набора Test. Три снимка режимов больших чисел должны использовать одинаковое кадрирование для прямого визуального сравнения.
