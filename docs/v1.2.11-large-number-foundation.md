# v1.2.11 Large Number System foundation

This feature branch introduces the first presentation-only slice of the Large Number System.

- Shared compact formatter with K/M/B/T/Qa/Qi/Sx/Sp/Oc/No/Dc suffixes.
- Up to two decimal places with boundary promotion, for example 999999 -> 1M.
- Rune scalar and composite tooltip values use the shared formatter.
- Player HUD coins, crystals, and damage use compact values.
- Mob health and visible reward amounts use compact values.
- Rune resource/currency panel balances use compact values.
- Internal gameplay calculations, persistence, and packet value types are intentionally unchanged in this foundation slice.
- Overflow/storage type auditing remains a later v1.2.11 step.
