# v1.2.11 Large Number System

This feature branch introduces shared large-number presentation and arbitrary-precision storage for the player-facing values covered by v1.2.11.

- Three client-selectable display modes: `SIMPLIFIED` (Упрощенный), `FULL` (Полный), and `ENGINEERING` (Инженерный).
- Simplified and Full letter suffixes cover every E3 step through `E3000`; values above that range fall back to engineering notation.
- Simplified keeps compact suffixes such as `Uvg`, `Qavg`, `Ce`, `Vgc`, and `Nvnnc`.
- Full uses more descriptive but bounded suffixes such as `Ce`, `Vigce`, `Unvigce`, `Duce`, `Quing`, and `Novnong`.
- Letter suffixes use one leading capital only; remaining letters are lowercase.
- `E303` is displayed as `Ce` in both letter modes.
- Engineering mode uses exponents in multiples of three, for example `1250 -> 1.25E3`.
- Display values use at most two decimal places with `HALF_UP` rounding and trailing-zero trimming.
- Legacy letter suffixes remain accepted as input where unambiguous.
- Rune values, HUD resources, managed-mob HP/rewards, and other migrated displays use the shared formatter without changing their exact stored values.
