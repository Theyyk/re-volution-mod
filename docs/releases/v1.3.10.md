# RE:volution Mod v1.3.10

`v1.3.10` фиксирует Test Foundation как отдельный технический stable release поверх gameplay baseline `v1.3.9`.

## Что добавлено

- JUnit Jupiter `5.10.3` подключён к стандартной Gradle-задаче `test` через `useJUnitPlatform()`.
- Сохранены все 30 прежних standalone Java regression runners, которые продолжают входить в `check` и `build`.
- Добавлены 22 JUnit-теста для критичных service/repository сценариев progression и stage transitions.
- Добавлены in-memory repository fixtures для изолированной проверки cache/persistence semantics без MongoDB.
- CI публикует XML/HTML JUnit reports отдельным artifact и завершает сборку ошибкой, если JUnit не выполнил ни одного теста.

## Покрытие

### Mob progression

9 тестов покрывают failed/retry paths, idempotent unlock, каскадные `revoke/reset`, cache invalidation, player isolation, invalid inputs и filtering configuration.

### Stage transition service

6 тестов покрывают configure/clear persistence, validation до записи, overlapping zones, legacy geometry, deterministic nearest ties и filtering invalid entries.

### Stage transition trigger service

7 тестов покрывают reconfigure без потери сообщений, selective clear, invalid inputs, persistence failure/cache safety, clear/reload и вычисление направления соседних stages.

## Что не менялось

Gameplay production logic относительно `v1.3.9` не изменялась, кроме version metadata. `v1.3.10` не добавляет новую игровую механику, не меняет MongoDB schema, экономику, progression contract, teleport semantics или Realm runtime.

Тесты не заменяют runtime/integration acceptance для реального Forge lifecycle, collision/support, player tick, delayed trigger execution, transport или MongoDB integration.

## Инфраструктура

DEV Docker dispatcher теперь принимает только успешный `push` ветки `develop` этого репозитория. Stable tags, `main`, feature/fix ветки, PR и fork не запускают DEV publication chain. Исторический кейс `v1.3.9` закреплён regression-тестом routing policy.

## Проверки release gate

Перед promotion подтверждаются:

1. согласованность `build.gradle`, `mcmod.info` и `RevolutionMod.VERSION` = `1.3.10`;
2. 30 прежних regression runners;
3. 22 JUnit-теста;
4. architecture/structure/version/release-note guards;
5. packaged JAR без test classes;
6. exact-main CI перед annotated tag.
