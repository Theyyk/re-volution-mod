# RE:volution Mod v1.3.10

`v1.3.10` - технический релиз Test Foundation без новой gameplay-механики.

## Добавлено

- JUnit Jupiter 5.10.3 подключён к стандартному Gradle `test`.
- Добавлен service-level regression suite поверх существующих standalone regression tasks.
- Добавлены deterministic in-memory fixtures для business logic и persistence/cache paths без запуска Minecraft, OpenGL или MongoDB.
- CI публикует JUnit XML/HTML reports и завершает build ошибкой, если JUnit tests не были выполнены.
- Усилена regression-защита DEV dispatcher от попадания stable/tag workflow в DEV channel.

## Gameplay

Gameplay baseline v1.3.10 соответствует стабильному поведению v1.3.9. Новых player-facing gameplay mechanics этот релиз не добавлял.

## Проверки

Финальный stable build выполнял 22 JUnit tests без ошибок и 30 существующих standalone regression runners.

`v1.3.10` служит тестовой и процессной основой для дальнейших gameplay-итераций, начиная с v1.3.11.
