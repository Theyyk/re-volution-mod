# v1.2.8 — фундамент ресурсов и действий рун

Версия v1.2.8 закрепляет фиксированную модель валют и ресурсов рун и переводит игровые операции с ними на единый серверный контракт. Эта версия не завершает экономику рун, а создаёт безопасную основу для последующих цен, наград и действий.

## Изменения

- Каталог ресурсов зафиксирован: `coins`, `crystals`, `rune_dust`, `rune_shards`, `rune_cores`.
- Динамическое создание и удаление пользовательских ресурсов через `/customresource` удалено; команда остаётся только для просмотра списка и баланса.
- Добавлен общий серверный контракт действий с ресурсами: проверка достаточности, безопасное списание и выдача.
- Списание не может увести баланс ниже нуля.
- Платное пробуждение рун переведено на общий resource/action API без изменения существующей логики прогрессии.
- Награды кастомных мобов переведены на тот же общий контракт выдачи ресурса.
- Старые методы `getLightnings` / `setLightnings` удалены из Mongo API, а новые записи игроков больше не создают поле `lightnings`.
- `lightnings` исключён из действующей модели ресурсов и сохраняется только как историческое имя для очистки старых данных.
- Обновлена документация по валютам, ресурсам рун и командам.
- Добавлены регрессионные проверки фиксированного каталога и resource/action foundation.

## Границы версии

v1.2.8 — foundation-релиз. Он не задаёт финальные цены, баланс доходов и расходов, формулы полной экономики или механику **Улучшения руны**. Текущий технический baseline покупки, дубликатов и платного пробуждения остаётся прежним.

Ранги рун остаются **Обычная → Улучшенная → Продвинутая**. Раздел **РЕСУРСЫ РУН** включает Пыль рун → Осколки рун → Ядра рун и не является отдельным ресурсом.

## Проверка

Runtime-проверка подтвердила корректный фиксированный каталог ресурсов, работу Admin / Test Panel, безопасное списание, покупку рун, компенсацию дубликатов, платное пробуждение, награды мобов и отсутствие регрессий multi-status GUI.

CI feature-ветки, develop и main также успешно пройден до подготовки релиза.
