# v1.4.2 — Rune Purchase + Duplicates

## Назначение

`v1.4.2` переводит покупку рун и награды за дубликаты на канонический Balance Layer, созданный в `v1.4.1`.

### Добавлено

- Generic string `values` в canonical balance config для resource ids и других нечисловых параметров.
- `RunePurchaseBalanceService` как отдельный rune-domain адаптер поверх generic Balance Core.
- Runtime bootstrap bundled canonical balance snapshot.
- Отдельные curve ids по статусу и рангу для purchase и duplicate reward.
- Тестовое покрытие parser/codec values, bundled defaults, pricing by opened slots и integer bridge к текущему `ResourceService`.

### Изменено

- Цена покупки status-коллекции теперь вычисляется перед каждой попыткой по числу реально открытых уникальных rune slots.
- Новый слот увеличивает purchase progression на один шаг.
- Дубликат оплачивается полностью, выдаёт настроенную награду, но не увеличивает purchase progression.
- `buyAll` последовательно пересчитывает цену каждой следующей попытки вместо `balance / unitCost`.
- Poison сохраняет placeholder purchase cost `100` coins; duplicate reward установлен в согласованный стартовый `1` rune dust.

### Совместимость

- Legacy-коллекции без rune status пока сохраняют старую стоимость и старый purchase path.
- Enhancement, rank-up, rune effects и mob balance пока продолжают использовать существующие источники настроек до своих отдельных `1.4.x` миграций.
- Player/Mongo schema не меняется.
- Balance Core продолжает хранить числа как `BigDecimal`; rune purchase adapter временно требует целые значения в диапазоне текущего integer `ResourceService`.
