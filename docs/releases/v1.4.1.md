# v1.4.1 — Balance Core

## Назначение

`v1.4.1` добавляет канонический фундамент системы баланса, при этом намеренно сохраняет игровое поведение, выпущенное в `v1.4.0`.

### Добавлено

- Иммутабельные канонические определения баланса с `balanceSchemaVersion: 1`.
- JSON-парсер для канонических balance-данных.
- Строгая семантическая валидация до активации.
- Детерминированные режимы кривых `FIXED`, `TABLE`, `FORMULA` и `PIECEWISE`.
- Значения баланса на `BigDecimal` без сужения до `int`, `long` или `double` внутри нового Balance Core.
- Детерминированный canonical JSON и SHA-256 revision баланса.
- Атомарная семантика `prepare` / `activate`: невалидный конфиг никогда не заменяет предыдущий активный snapshot.
- JUnit-покрытие парсера, валидации, математики кривых, hashing, больших значений и атомарной активации.

### Совместимость

- `RuneEconomyConfig` остаётся источником gameplay-настроек в этом релизе.
- Покупка рун, дубликаты, усиление, rank-up, combat effects, HP/награды/population мобов и Admin stage editing не меняются.
- Миграция player-save или Mongo schema не требуется.
- Balance-файл пока не загружается автоматически при старте сервера.
- Интеграции с Google Sheets или live Google API нет.

## Далее

`v1.4.2` переведёт Rune Purchase и duplicate rewards на канонический Balance Layer после закрепления контракта Balance Core.
