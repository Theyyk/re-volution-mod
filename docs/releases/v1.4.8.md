# RE:volution Mod v1.4.8

## Назначение релиза

`v1.4.8` завершает текущий этап Balance Phase 2 стабильным read-only Export Contract для внешних инструментов. Активный Balance Core snapshot можно получить в canonical и spreadsheet-friendly представлении без отдельного balance state и без прямого подключения gameplay-мода к Google API.

## Balance Export Contract v1

Добавлен защищённый маршрут:

- `GET /api/v1/balance/export` - read-only экспорт текущего active Balance Core snapshot.

Маршрут использует существующий capability `balance.read`, требует пустой request body и остаётся внутри той же loopback-only HMAC Admin API границы и Minecraft server-thread handoff.

Ответ содержит:

- `exportContractVersion = 1`;
- `revision` активного Balance Core snapshot;
- `balanceSchemaVersion`;
- `canonicalConfig` - authoritative canonical JSON;
- `columns = ["pointer", "type", "value"]`;
- deterministic `rows` для табличной обработки.

## Spreadsheet-friendly projection

Каждая строка соответствует одному leaf-значению canonical JSON и содержит:

- RFC 6901 JSON Pointer;
- тип `string`, `number`, `boolean` или `null`;
- текстовое представление значения без числового narrowing через `double`, `float`, `int` или `long`.

Для массивов используется числовой индекс. Символы `/` и `~` внутри object keys экранируются по RFC 6901 как `~1` и `~0`. Точки в balance IDs остаются обычной частью key.

Для семантически одинакового Balance Core config export сохраняет одинаковые `revision`, `canonicalConfig`, порядок строк и значения. Decimal formatting берётся из существующего canonical codec Balance Core.

## Source of truth

`canonicalConfig` вместе с `revision` остаётся источником истины. `rows` - только read-only проекция для внешних таблиц и инструментов. Экспорт строится непосредственно из активного immutable `BalanceSnapshot` и не создаёт отдельное persisted или runtime balance state.

## Google Sheets readiness

`v1.4.8` не добавляет прямой Google Sheets API вызов из gameplay-мода.

Gameplay-мод не хранит и не обрабатывает:

- Google API keys;
- OAuth tokens;
- Google service-account credentials;
- другие внешние integration secrets.

Будущий Control или другой внешний инструмент может использовать Export Contract v1 как стабильный входной формат и самостоятельно преобразовывать его в Google Sheets.

## Что не меняется

- Balance Preview/Apply из `v1.4.7` сохраняет прежний контракт.
- `balance.write` и write-path не расширяются.
- Bundled gameplay balance values не меняются.
- Rune и Mob Balance mechanics не меняются.
- Mongo schema не меняется.
- Mob identity/type, population, модели, PNG, spawn coordinates, zones, stage/world topology не входят в export mutation, потому что export вообще не мутирует gameplay.

## Проверки

Добавлены regression tests для:

- отказа export при отсутствии active snapshot;
- deterministic export семантически эквивалентных configs;
- соответствия export revision active snapshot;
- canonical decimal formatting;
- deterministic array pointers;
- RFC 6901 escaping для `/` и `~` в keys.

Полный Forge build, architecture guards и Admin API security guards остаются обязательными.
