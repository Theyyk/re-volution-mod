# v1.2.3 — компенсация за дубликаты рун

Версия v1.2.3 добавляет компенсацию за дубликаты для статуса Яд.

## Изменения

- Каждый дубликат руны статуса Яд по умолчанию дает 10 Пыли рун (`rune_dust`).
- Несколько дубликатов суммируются.
- Компенсация начисляется на сервере и сохраняется в MongoDB.
- Баланс ресурса обновляется в интерфейсе сразу после покупки.
- Дубликат не создает вторую копию руны в коллекции.

## Настройка

Расчет вынесен в отдельную конфигурацию. Поддерживаются режимы `FIXED`, `BY_RANK` и `FORMULA`. Ивент-множитель применяется поверх базового расчета.

## Проверка

CI feature-ветки, develop и main пройден. Runtime-тест в игре также пройден.
