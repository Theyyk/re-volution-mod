# Custom GUI Mod v1.1.3

Переработан основной GUI рун и интерфейс игрока:

- обновлена компоновка статистики, ресурсов, персонажа, снаряжения и рун;
- добавлен каркас 16 слотов снаряжения и 5 сборок экипировки;
- добавлены поиск рун по названию и типу;
- добавлена покупка рун `x1`, `x5`, `x10`, `x100`;
- восстановлено пробуждение рун и состояние максимального ранга;
- добавлены подсказки действий с рунами;
- добавлен blur фона с корректным управлением shader lifecycle;
- правая навигация упрощена до вкладки рун и кнопки закрытия;
- добавлены placeholder-данные прогрессии игрока;
- добавлена защита CI от permission-pending GUI-ассетов;
- исправлена загрузка artifacts для feature-веток в GitHub Actions.
