# RE:volution Mod v2.3.0

## Назначение релиза

`v2.3.0` переводит Rune System из одной рабочей коллекции в общий gameplay foundation из семи фиксированных коллекций.

Основная цель версии - закончить архитектурный и runtime-контракт коллекций, рангов, статусов, эффектов и persistence. Числа новых коллекций, технические названия и часть content-настроек имеют статус **ZBT Draft**, не Final. Финальный визуальный polish в релиз не входит.

## Семь коллекций и 26 слотов

Rune System теперь содержит семь фиксированных коллекций по 26 persistent rune slots каждая.

- Collection 1 сохраняет существующие CLICK + POISON identity, gameplay math и совместимость старых данных.
- Collections 2-7 используют стабильные `RuneCollectionId` и `RuneSlotId`, независимые от расположения элементов GUI.
- Production catalog валидируется как ровно 26 уникальных слотов на каждую коллекцию.
- Технические названия новых рун допустимы на текущем этапе и не являются финальным контентом.

## Permanent unlock progression

Collection 1 открыта по умолчанию.

Следующая коллекция permanently открывается в первый момент, когда предыдущая фактически содержит не менее 13 рун ранга `IMPROVED` или выше.

- `ADVANCED` и `MYTHIC` также считаются в прогресс `13/13`.
- Unlock сохраняется в persistence и после получения никогда не снимается.
- Цепочка работает последовательно от Collection 1 до Collection 7.
- Legacy Collection 1 с уже существующими 13 Improved+ детерминированно открывает Collection 2 при первой проверке.
- Дополнительная восьмая коллекция не создаётся.

## Ранги

Активные gameplay ranks:

- `ORDINARY` - Обычная;
- `IMPROVED` - Улучшенная;
- `ADVANCED` - Продвинутая;
- `MYTHIC` - Мифическая.

`ANCIENT` / Древняя зарезервирована в модели, но в `v2.3.0` не участвует в gameplay progression.

Awakening, factual nested progression и Rank Revert работают через общий rank model. `MYTHIC -> ADVANCED` использует тот же generic revert path без отдельного Mythic service.

## Enhancement

Enhancement остаётся независимым свойством rune slot.

- hard cap усиления отсутствует;
- существующая стоимость до `+50` сохранена;
- после `+50` действует уже введённый data-driven unlimited tail;
- enhancement сохраняется при rank-up, Rank Revert и Prestige reset.

## Damage/status channels

Общий damage contract содержит каналы:

- `CLICK`;
- `POISON`;
- `BURNING`;
- `BLEEDING`;
- `CURSE`;
- `WITHER`;
- `DECAY`.

Новые status channels используют общий `RuneStatusDamageRuntime`, а не отдельные сервисы для каждого элемента.

Status damage проходит через обычный server-authoritative damage path. `GameplayDamageContext` маркирует источник, после чего neutral gameplay boundary публикует только фактически снятый HP. Prestige и другие системы получают подтверждённый damage result и не вызываются напрямую из status engine.

Legacy POISON execution Collection 1 сохранён отдельно там, где это необходимо для неизменности существующей C1 математики и regression behavior.

## Generic rune effects

Balance Core и runtime поддерживают общий effect model, включая:

- flat и multiplier damage;
- all-damage multiplier;
- vulnerability;
- effectiveness;
- targeted power;
- proc chance и proc damage multiplier;
- monster gold bonus;
- monster resource bonus;
- pet XP multiplier;
- delayed damage bonus;
- temporary damage multiplier;
- temporary effect duration;
- enhancement effectiveness;
- hybrid multi-effect runes.

Timed и delayed effects используют общие параметры target/trigger/condition/duration/delay и не требуют status-specific engines.

`PET_XP_MULTIPLIER` присутствует в definitions, Balance Core и tooltip, но Pet System ещё не реализован. Поэтому в `v2.3.0` этот канал является безопасным runtime no-op и не влияет на combat/rewards.

## Rewards

Gold и rune-resource bonuses разделены.

Active fixed collection может давать собственный `MONSTER_GOLD_MULTIPLIER` и `MONSTER_RESOURCE_MULTIPLIER` через общий collection-aware resolver.

- coin bonus не превращается в resource bonus;
- rune-resource bonus применяется к canonical rune resources;
- `crystals` не получают rune resource bonus;
- Collection 1 сохраняет старое reward behavior.

## Prestige integration

Prestige reset подключён к Rune System через общий reset participant.

При подтверждённом Prestige reset:

- `ORDINARY` и `IMPROVED` сбрасываются до `ORDINARY`;
- `ADVANCED` и `MYTHIC` сохраняются;
- enhancement сохраняется;
- unlocked collections не закрываются.

Reset policy использует generic rank comparison и не содержит Mythic-specific ветки.

## Persistence и migration

Существующий Mongo shape и legacy deck/card storage сохранены как compatibility boundary.

Дополнительно сохраняется permanent collection state через `runeCollections.unlockedCollections`.

`v2.3.0` покрывает restart/migration regression:

- Collection 1 старых игроков продолжает загружаться без потери rune identity;
- Mythic rank сохраняется;
- unlock state сохраняется между restart;
- enhancement state не сбрасывается;
- legacy factual progress может открыть следующую коллекцию при первой deterministic evaluation.

## Balance Core

Новые коллекции и generic effects подключены через canonical Balance Core overlays.

Validation отклоняет invalid collection/rank/effect/target/duration/multiplier/unlock/resource/transition definitions и не публикует partial snapshot.

Для production catalog проверяется полнота всех семи коллекций и уникальность 26 slots каждой.

Текущие значения Collections 2-7 остаются **ZBT Draft**. Stable status версии означает стабильность архитектуры, persistence и runtime contract, а не Final balance.

## Functional Rune GUI

Rune GUI расширен функциональным metadata layer без изменения legacy rune-state packet format.

Интерфейс умеет показывать:

- selector семи коллекций;
- locked/unlocked state;
- active collection;
- 26 rune slots;
- factual rank и enhancement;
- effect tooltip;
- purchase/awakening/enhancement actions;
- прогресс `X/13` к следующей коллекции;
- MYTHIC state;
- PET XP effect как поддерживаемое определение, даже при runtime no-op.

Это функциональный skeleton. Финальный арт, названия и visual polish остаются отдельной задачей.

## Out of scope

В `v2.3.0` не входят:

- Ancient gameplay progression;
- Collection Meta Reset;
- Chest Upgrade;
- Pet gameplay, XP и slots;
- Artifacts;
- Forge;
- Mastery Quest;
- Generic Quest System;
- final balance;
- final names/textures/art;
- major visual polish.
