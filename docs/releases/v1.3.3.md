# RE:volution Mod v1.3.3

v1.3.3 — небольшой релиз совместимости клиента и resource pack. Realm foundation в эту версию не входит и переносится на v1.3.4.

## Изменения

- Добавлено обязательное применение server resource pack для клиентов RE:volution.
- Ссылки на ресурсы рун выровнены под namespace `revolution`.
- Исправлена очистка resource-pack network handler при logout/reconnect, включая уже закрывающееся соединение.
- Подготовлена совместимость с RE:volution Client v1.0.0 и production launcher flow.

## Совместимость

Minecraft 1.12.2, Forge 14.23.5.2859, Java 8 и существующая gameplay/MongoDB совместимость сохраняются. v1.3.3 не добавляет Realm/Location/Mob Position механику.

## Roadmap после v1.3.3

- v1.3.4: Realm foundation.
- v1.3.5: Mongo Location + Mob Position definitions.
- v1.3.6: fixed mobs runtime.
- v1.3.7: damage contribution, rewards и HP rollback.
- v1.3.8: progression.
- v1.3.9: scaling, dynamic Realm count и runtime optimization.

## Проверки

Resource pack и namespace fixes были проверены в runtime. Logout/reconnect после cleanup fix также принят. Финальный release-prep HEAD должен дополнительно пройти exact-head CI и сборку JAR `RE-volution-1.3.3.jar`.
