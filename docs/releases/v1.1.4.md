# Custom GUI Mod v1.1.4

Обновлено визуальное оформление GUI поверх логики v1.1.3:

- перенесены оформление панелей, статистики, ресурсов, навигации и сетки рун из архивного варианта;
- добавлены экранные шрифты Five / Seven без замены глобального шрифта Minecraft;
- обновлены пиксельные иконки, отображение рангов и состояний кнопок;
- восстановлены двухстрочные подписи покупки и улучшения руны;
- опубликованы runtime-скриншоты и синхронизирована документация resource pack;
- добавлены сведения об источнике шрифтов и ответе поддержки Cristalix.

[Инвентаризация, roadmap и runtime checklist](../v1.1.4-archive-integration.md).
