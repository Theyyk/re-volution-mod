# Custom GUI Mod v1.1.1

#### GUI

- полностью переработан каркас интерфейса;
- добавлена адаптивная компоновка;
- добавлены панели статистики, ресурсов, персонажа, рун и навигации;
- добавлен каталог из 26 фиксированных позиций;
- добавлены ранги, типы и массовая покупка рун;
- добавлена отдельная модель `RuneInventory` и регрессионные тесты.
