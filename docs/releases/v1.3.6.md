# RE:volution Mod v1.3.6

`v1.3.6` подключает runtime мобов к фундаменту Location + Mob Spawn из `v1.3.5`.

## Runtime Mob Spawn

- Один Mob Spawn создаёт ровно одного физического моба в каждом Realm, к которому относится его scope.
- Несколько Mob Spawn могут ссылаться на один и тот же логический mob definition.
- `PLAYER_REALMS` разворачивает один и тот же spawn-slot в Realm 1, Realm 2 и Realm 3 с одинаковой геометрией и разными dimension ID.
- `REALM_0` создаёт моба только в Realm 0.
- Если для старого enabled-моба ещё нет v1.3.6 spawn-slot, сохраняется legacy Realm 0 спавн по старым координатам.

## Режимы

Поддерживаются все четыре комбинации:

- `FIXED_POINT` + `STATIONARY`;
- `FIXED_POINT` + `ROAMING`;
- `RANDOM_AREA` + `STATIONARY`;
- `RANDOM_AREA` + `ROAMING`.

Для `RANDOM_AREA` каждый игровой спавн заново независимо выбирает X/Z внутри круглой Location Area, а Y ищется по безопасной поверхности карты. После убийства и последующего респавна выполняется новый random roll. Новая точка не обязана отличаться от предыдущей и может случайно совпасть с ней. Выбранная точка является initial/fallback point только для текущей жизни физического моба.

## Roaming

`ROAMING` использует ту же круглую Location Area, что и random spawn. При приближении к краю моб получает путь внутрь зоны. Если он всё же выходит дальше примерно чем на два блока за радиус, он возвращается на initial/fallback point своей текущей жизни. Для `RANDOM_AREA` после следующей смерти этот fallback будет выбран заново.

## Настройка для теста

- `/custommob location set <locationId> <radius> [name]` создаёт или обновляет Location с центром в текущей позиции игрока по X/Z.
- `/custommob location list` показывает Locations.
- `/custommob spawn set <locationId> <spawnId> <mobName> <fixed|random> <stationary|roaming> <player|realm0>` создаёт или обновляет физический spawn-slot с fallback-точкой в текущей позиции игрока.
- `/custommob spawn list <locationId>` показывает spawn-slots Location.
- `/custommob spawn remove <locationId> <spawnId>` удаляет spawn-slot.

После изменения конфигурации managed mobs автоматически перезагружаются.

## Не входит в v1.3.6

Contribution/reward rework, HP rollback, progression и scaling остаются следующими этапами и в эту версию не добавляются.
