# v1.2.7 — фундамент нескольких статусов рун

Версия v1.2.7 переводит существующий жизненный цикл рун с Poison-only предположений на общую multi-status основу. Покупка, компенсация дубликатов, прогрессия, платное пробуждение, синхронизация клиента и переключение GUI теперь работают через активный статус.

## Изменения

- Добавлен центральный реестр статусов рун и единая маршрутизация по активному `statusId`.
- Экономическая конфигурация изолирована между статусами: цена покупки, ресурс оплаты, дубликаты и пробуждение не должны протекать между коллекциями.
- Активный статус и связанные с ним параметры экономики синхронизируются на клиент.
- Встроенный статус Poison отображается пользователю как **Яд** без обязательной миграции старого имени коллекции в MongoDB.
- Переключение между статусами больше не показывает промежуточную надпись `Загрузка...` на кнопке покупки.
- Служебные сообщения вида `Активная колода: ...` больше не выводятся в чат при переключении.
- Для отсутствующих rune-текстур используется безопасный fallback на ванильный порох.
- После выключения и повторного включения resource pack индивидуальные текстуры рун корректно восстанавливаются после reload.
- Добавлены регрессионные проверки multi-status маршрутизации и изоляции экономики.

## Границы версии

v1.2.7 — это именно foundation. Полный набор будущих наносящих урон статусов, их иконки, механики урона, экономика и финальный баланс в эту версию не входят.

Текущий игровой baseline по-прежнему строится вокруг статуса **Яд**. Ранги рун остаются **Обычная → Улучшенная → Продвинутая**. Механика **Улучшения руны** остаётся отдельной и всё ещё не реализована; платное пробуждение из v1.2.6 не подменяет её.

## Проверка

Runtime-проверка подтвердила корректное переключение между статусами, отсутствие `Загрузка...`, отсутствие служебных сообщений в чате, правильные подписи цен, изоляцию данных статусов и корректный цикл resource pack: включён → fallback после выключения → восстановление индивидуальных rune-текстур после повторного включения.

CI feature-ветки, develop и main также успешно пройден до подготовки релиза.
