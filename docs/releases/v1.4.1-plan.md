# v1.4.1 acceptance gates

The Balance Core change is acceptable only when:

1. canonical JSON parses into immutable definitions;
2. schema/version and curve semantics are validated before activation;
3. FIXED, TABLE, FORMULA and PIECEWISE evaluation is deterministic;
4. balance values stay in BigDecimal inside the new core;
5. revision is semantic and deterministic;
6. prepare does not mutate active state;
7. failed activation keeps the previous snapshot intact;
8. gameplay behavior from v1.4.0 is unchanged because no existing consumer is switched yet;
9. JUnit, architecture guards and the full repository build are green.
