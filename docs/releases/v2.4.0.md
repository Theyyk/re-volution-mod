# RE:volution Mod v2.4.0

## Добавлено

- Добавлена полноценная Pet System с техническим каталогом из 18 питомцев и server-authoritative состоянием.
- Добавлены 8 normal Pet Slots на текущий Prestige run и 2 permanent premium slots за Crystals.
- `Фрагменты знаний` официально используют существующий `runBranchCurrency`: normal slots покупаются из этого run-scoped баланса, а начисление фрагментов вынесено в Balance Core.
- Добавлен Run Exchange foundation для будущего обмена Фрагментов знаний на игровые ресурсы. Конкретные exchange offers и rates в v2.4.0 намеренно не заданы.
- Добавлены ранги Pets `ORDINARY → IMPROVED → ADVANCED → MYTHIC`; `ANCIENT` остаётся зарезервированным и не участвует в gameplay.
- Добавлены Pet XP и Level без gameplay hard cap. XP начисляется только активным питомцам за фактическое online-время; `PET_XP_MULTIPLIER` влияет на всех активных Pets, включая самого источника бонуса.
- Добавлены Pet Awakening, real-time cooldown, deterministic compaction активных слотов и generic Rank Revert на один ранг через `CTRL + ПКМ`.
- Добавлен функциональный Pet tab в существующий RPG inventory flow без финального visual polish.
- Pet effects подключены к общему `EffectResolver`; поддерживаются additive multipliers, trade-offs и точное итоговое `×0`. Autoclick работает server-authoritative как CLICK damage.

## Persistence и Prestige

- Permanent Pet progression и run-scoped Pet state разделены и сохраняются в MongoDB с restart safety.
- Prestige reset выполняет selective wipe в том же guarded commit: `ORDINARY` и `IMPROVED` удаляются, а `ADVANCED+` сохраняют ownership, rank, level и XP.
- Permanent premium entitlement сохраняется между runs.
- Run-scoped normal slots, purchase index, cooldowns, lower-rank purchases и Фрагменты знаний сбрасываются на новом Prestige run.
- Выбранные `ADVANCED+` Pets сохраняют selected state через Prestige reset и привязываются к новому factual run state.

## Баланс

- Pet purchase prices, effect values, XP curve, rank scaling, normal slot price curve, cooldown, premium slot costs и Fragment rewards находятся в Balance Core.
- Числа v2.4.0 имеют статус ZBT Draft и не считаются Final balance.
- Normal slot price использует непрерывный purchase index внутри run; Pet Awakening не сбрасывает этот индекс, Prestige сбрасывает.

## Проверка

- Добавлены regression tests для покупки и ownership, normal/premium slots, Awakening, cooldown, XP, self-benefit `PET_XP_MULTIPLIER`, stacking/`×0`, Rank Revert, deterministic sorting, selective Prestige reset, Mongo round-trip, packet round-trip, Run Exchange foundation и data-driven Fragment rewards.
- Существующие Rune, Prestige, Balance Core, Realm, Location, Admin API и architecture/security regression suites остаются обязательными.

## Вне области версии

- Ancient Pet gameplay.
- Финальные имена, арт и баланс Pets.
- Большой visual polish интерфейса Pets.
- Конкретные Run Exchange offers/rates.
- Forge gameplay, Artifacts, Mastery Quest, Generic Quest System и Collection Meta Reset.
