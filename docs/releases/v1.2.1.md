# RE:volution Mod v1.2.1

Версия v1.2.1 добавляет внутриигровую админ-панель для тестирования и управления состоянием игроков, ресурсов, рун и кастомных мобов, а также меняет пробуждение рун со средней кнопки мыши на левую.

Основные изменения:

- добавлена Admin / Test Panel, открываемая по F8 только для разрешённых сервером UUID;
- добавлен отдельный список администраторов, не зависящий от whitelist сервера Minecraft и OP-статуса;
- добавлен выбор онлайн-игрока для применения административных действий;
- добавлены инструменты сброса и заполнения рун NORMAL, SILVER и GOLD;
- добавлены действия с ресурсами: добавить, установить значение и обнулить, с выбором типа ресурса;
- добавлено управление кастомными мобами: создание, перенос точки спавна и удаление;
- добавлены выпадающие списки, пагинация, сводная информация и подтверждение опасных действий;
- пробуждение руны теперь выполняется левой кнопкой мыши вместо средней;
- исправлено выравнивание текстовых полей в Admin / Test Panel;
- CI теперь также запускается для изменений в `main`.

## Проверка

Перед подготовкой релиза успешно выполнены:

- CI feature-ветки;
- merge в `develop` и зелёный CI на `develop`;
- локальная проверка на постоянном сервере после merge в `develop`;
- merge `develop` в `main`;
- проверка работы CI на `main`;
- проверка версии `1.2.1` в `build.gradle` и `mcmod.info`.

Поддерживаемая среда остаётся прежней: Minecraft 1.12.2 и Forge 14.23.5.2859. Клиент и сервер должны использовать одинаковую версию мода.
