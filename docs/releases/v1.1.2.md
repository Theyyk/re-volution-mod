# Custom GUI Mod v1.1.2

#### Статус Яд и руны

- первая коллекция переведена с прежней тематики на статус **Яд**;
- обновлены названия и типы рун;
- каталог сохраняет 26 фиксированных физических позиций;
- добавлены 11 уникальных rune-иконок нового визуального набора.

#### Resource pack

- rune-artwork полностью вынесен из JAR в отдельный `re-volution-resource-pack`;
- сохранены те же `customguimod:` пути ресурсов, поэтому Java-код работает через стандартные `ResourceLocation`;
- игровые rune-иконки нормализованы до `128x128`.

#### Производительность

- удалено декодирование PNG через `ImageIO.read` из GUI-рендера;
- добавлен `RuneTexturePreloader` для прогрева текстур при инициализации клиента;
- устранён заметный лаг при первом открытии интерфейса.

#### Сервер и данные

- MongoDB URI и имя базы теперь задаются через JVM properties;
- Build/Test окружения могут использовать разные базы без изменения кода;
- расширена обработка покупки и синхронизации rune-состояния.
