# RE:volution Mod v1.2.2

Версия v1.2.2 добавляет три постоянных ресурса улучшения рун, разделяет валюту и материалы рун в интерфейсе, удаляет устаревшие «Молнии» и устраняет заметную задержку при первом открытии меню.

Основные изменения:

- добавлены три встроенных ресурса рун: `rune_dust` — «Пыль рун», `rune_shards` — «Осколки рун», `rune_cores` — «Ядра рун»;
- новые значения сохраняются в MongoDB в `players.resources.*`, а отсутствующие поля у существующих игроков считаются равными нулю;
- все три ресурса синхронизируются с клиентом через пакет статистики игрока;
- Admin / Test Panel поддерживает `set`, `add` и `zero` для каждого нового ресурса;
- блок ресурсов в основном GUI разделён на «ВАЛЮТА» с монетами и кристаллами и «РЕСУРСЫ РУН» с пылью, осколками и ядрами;
- устаревший ресурс `lightnings` удалён из активной модели и Admin / Test Panel;
- при старте сервера и входе игрока очищаются старые поля `lightnings` в MongoDB, а устаревшие награды мобов на этот ресурс удаляются;
- GUI-шрифты теперь предварительно загружаются при инициализации клиента, поэтому первое открытие меню больше не вызывает заметную паузу;
- версии в `build.gradle`, `mcmod.info` и `CustomGuiMod.VERSION` синхронизированы на `1.2.2`.

## Проверка

Перед подготовкой релиза успешно выполнены:

- CI feature-ветки;
- runtime-проверка интерфейса;
- проверка `set`, `add` и `zero` для Пыли рун, Осколков рун и Ядер рун;
- проверка сохранения значений после relog и перезапуска постоянного сервера;
- проверка удаления «Молний» из Admin / Test Panel;
- проверка отсутствия заметного фриза при первом открытии GUI;
- merge feature-ветки в `develop` и зелёный CI на `develop`;
- merge `develop` в `main` и зелёный CI на `main`.

Поддерживаемая среда остаётся прежней: Minecraft 1.12.2 и Forge 14.23.5.2859. Клиент и сервер должны использовать одинаковую версию мода.
