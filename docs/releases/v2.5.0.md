# RE:volution v2.5.0

## Основное

- Добавлен Mastery Reset как новый meta-progression слой поверх существующих Искусств.
- Mastery Reset становится доступен вручную только после достижения текущего `rankMetaLevelCap` всеми рангами активного Искусства.
- Успешный Mastery Reset повышает `masteryTier`, применяет новый cap и увеличивает `metaLevelGainPerRun`, сохраняя накопленные rank meta-levels и исторический лучший результат.
- Прогресс и Reset полностью изолированы между ветками Искусств.
- Автоматический Mastery Reset, quest/boss/timer/fail-state механики не добавляются.

## Reset и сохранение

- Обычный reset run сохраняет прежний server-authoritative lifecycle, runId guards и защиту от duplicate/stale запросов.
- Mastery Reset использует тот же централизованный reset path и canonical selective reset для Pets и Runes.
- Добавлен выбор режима Mastery Reset: normal или premium preserve.
- Premium preserve управляется Balance Core: отдельно задаются доступность, стоимость в Crystals и флаги сохранения Rune/Pet state.
- Списание Crystals выполняется атомарно вместе с guarded reset commit; при нехватке Crystals активный run не потребляется.
- Crystals, permanent Mastery state, historical best и rank meta-levels не сбрасываются.

## Balance Core

- Tier policy полностью data-driven: `masteryTier -> rankMetaLevelCap -> metaLevelGainPerRun`.
- Стоимость premium preserve и его preserve-флаги не зашиты в core logic.
- В bundled ZBT snapshot premium preserve по умолчанию выключен; конкретные варианты и стоимость будут назначаться балансом без изменения reset-кода.

## Совместимость

- Сохранения v2.4.1 загружаются с безопасными defaults и мигрируют на новый persistence schema при следующей записи.
- Legacy runtime placeholder `masteryQuestState` больше не является частью фактического Mastery state.
- Advanced+ Pet и Rune persistence, Enhancement, premium Pet Slots, Awakening, cooldown, Rank Revert и Fragment reset contracts сохраняют существующее поведение.

## Проверки

- Добавлены regression-тесты eligibility, tier progression, configured meta gain, cap clamp, branch isolation, manual-only reset, duplicate/stale safety, premium selection, Crystal checks и v2.4.1 migration.
