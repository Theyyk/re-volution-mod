# RE:volution Mod v1.3.4

Подготовка Realm foundation; PR #77 остаётся на проверке, merge/release не выполняется.

- Realm 0 — прежний административный overworld/dimension 0, в sync не участвует.
- Realm 1/2/3 используют dimension IDs 201/202/203, void generation и стартовые платформы.
- При входе игрок получает наименее населённый Realm; `/realm join` сохраняет административную проверку.
- При каждом старте dedicated-сервера DIM202/DIM203 полностью заменяются из DIM201
  до загрузки миров Forge. Между рестартами Realm независимы; изменения игроков в 2/3 сбрасываются.
- Добавлены блокировка save, подготовка обеих копий перед заменой, восстановление при
  ошибке публикации и остановка при незавершённой транзакции или отсутствии эталона.
- Сохранённые блоки стартового чанка не перезаписываются при входе/перезапуске.
- Исправлен импорт Biomes в генераторе Minecraft 1.12.2.
- Команда `/realm sync` отсутствует. MongoDB, общие player data, overworld и другие dimensions не заменяются.
- Исправленный локальный launcher сохраняет Test/world для Realm-ветки; прежние ветки сохраняют Build→Test workflow. Скрипт и Windows-проверка включены в tools/startup.

Версии Minecraft/Forge/Java и версия мода 1.3.4 сохранены. Location/Mob Position и
следующие этапы roadmap в эту правку не входят. Проверки и подробный локальный
runtime-чеклист: [Realm startup sync](../realm-startup-sync.md). Приёмка с клиентом
и реальным Forge-сервером требуется до merge; автоматические проверки её не заменяют.
