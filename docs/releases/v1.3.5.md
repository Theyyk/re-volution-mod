# v1.3.5

## Location and Mob Spawn foundation

- Adds circular Location definitions with shared X/Z gameplay areas.
- Adds one-slot-per-mob spawn definitions so many physical slots can reuse one mob definition and stat set.
- Adds independent spawn and movement switches for fixed/random placement and stationary/roaming behavior.
- Keeps Player Realms 1-3 on shared spawn geometry while allowing Realm 0 only when explicitly scoped.
- Adds lookup/geometry service rules and regression coverage.

Runtime entity spawning, respawn, roaming AI, surface-Y resolution and out-of-bounds recovery are not part of this foundation.
