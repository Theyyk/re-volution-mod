# v2.13.0 — Unified UI/GUI System (Variant A)

**Статус:** DRAFT / RELEASE READINESS. Не опубликован как Stable. Текущий Stable — v2.12.2. Этот документ описывает целевой release scope, а не завершённый release.

## Scope относительно v2.12.2

- UI-02: Ordinary / Unique Runes, Pets, Aura, background blur и исправления rune progression/purchase.
- UI-03: Mastery Progression/Ranks, M1 effects, R2 rewards, Reset, Premium Preserve, Combat Projection, Gods/Arts integration.
- UI-04: Aura, Quests, Run Exchange.
- UI-05: Locations, Stages, Stage Travel, Fast Auto, Settings.
- UI-06: Localization, Crystal operation notifications, Share/Hover, God Worship presentation, blur и Unified UI regression.
- Принятые отдельные исправления: RESET-ECONOMY-01, UI-06-R1, UI-02-C-R2 (Unique Rune R3/R4), Aura shared nonce/reconnect, God Worship backpressure, BC-01, BC-02 и BC-02-R1.

## Неизменяемые контракты

- Server authority и player saves; без ручной MongoDB migration и удаления сохранений.
- Текущие Balance Core, Reset Economy, Mastery, Unique Rune R4, Aura/God fixes и все существующие packet IDs.
- Защита от отрицательных ресурсов, двойных списаний, повторных Reset/replay и устаревших запросов.
- Minecraft 1.12.2, Forge 14.23.5.2859, Java 8; фактическая client/server compatibility требует отдельного подтверждения по immutable candidate.

## Приёмка и выпуск

- Исторические DEV Minecraft QA относятся к соответствующим SHA/candidates и не приравниваются к новому integrated QA.
- Обязательные release gates v2.13.0: version consistency, build/JUnit/regression/CI, artifact identity (JAR SHA-256/OCI digests/Client manifest), release blockers, release report и отдельное согласие владельца на Stable promotion.
- По обновлённому решению владельца полный Multiplayer QA A–F **исключён из release gates v2.13.0** и будет выполнен владельцем отдельно перед v3.0.0. Это не означает, что concurrency/player-isolation тесты считаются пройденными; автоматические проверки продолжают действовать.
- Issue #72 (External Admin), Full Rune Collections content и V03 — вне scope.
- Stable promotion и PROD deployment — независимые permission gates. Не создавать тег v2.13.0 и не обновлять PROD без отдельных разрешений.
- При обнаружении release-blocking P0/P1 — минимальная правка через feature PR, exact-head CI, ordinary merge и новый immutable candidate.
