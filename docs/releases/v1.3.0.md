## RE:volution Mod v1.3.0

v1.3.0 завершает переход проекта к брендингу RE:volution Mod, новой структуре пакетов и namespace `revolution`, сохраняя совместимость существующих данных и игровую механику.

### Добавлено
- Финальная модульная структура Java-пакетов для bootstrap, client, network, admin, commands, combat, player, mob, persistence, resource, number и rune-кода.
- Постоянные CI-проверки актуальной структуры пакетов и публичного брендинга.
- Серверный rate limiter и клиентский mini-cooldown для массового усиления рун, защищающие server thread от burst-нагрузки.
- Регрессионная проверка enhancement rate limiter в общем `gradle check`.

### Изменено
- Публичный брендинг приведён к `RE:volution Mod`, Java package — к `com.example.revolution`, main class — к `RevolutionMod`.
- Forge-safe mod id и namespace ресурсов изменены на `revolution`, сетевой канал — на `revolution:main`.
- Имя артефакта изменено на `RE-volution-<version>.jar`.
- Клиентские GUI/rune-классы, transport/server handlers и тесты разнесены по соответствующим пакетам без массового расширения visibility.
- Конфигурационные пути и system properties используют новые имена RE:volution с сохранённым legacy fallback там, где это требуется для совместимости.

### Исправлено
- Устранена перегрузка сервера при автокликере по `x100` усилению: быстрые повторные запросы отбрасываются до постановки работы в server-thread queue.
- Клиент больше не накапливает burst-запросы усиления и не пролагивает при быстром нажатии.
- Namespace мода и отдельного resource pack согласован на `revolution`, поэтому rune-текстуры корректно загружаются с актуальным набором ресурсов.

### Совместимость
- Mongo collections/keys и существующая схема данных сохранены, включая `decks`, `cards`, `cardIndex`, `activeDeck` и `runeEnhancements`.
- Discriminator IDs 0–7, порядок и стороны регистрации сетевых сообщений сохранены.
- Механика `x1/x5/x10/x100`, стоимость и случайные независимые попадания усилений по 26 слотам не изменены.
- Optional-client режим для vanilla-клиентов без мода сохранён.
- Отдельный resource pack остаётся в репозитории `re-volution-resource-pack`; актуальные assets используют namespace `revolution`.

### Проверка
- Package finalization прошёл exact-head и post-merge CI и принят в runtime.
- Актуальный 128×128 resource pack проверен вручную: индивидуальные rune-текстуры загружаются корректно.
- Enhancement anti-spam прошёл exact-head CI, runtime с автокликером и post-merge CI без `Can't keep up!` и клиентских лагов.
