# RE:volution v2.4.1

## Основное

- Pet XP больше не повышает уровень автоматически: XP накапливается, а уровень питомца применяется отдельным server-authoritative действием Level Up.
- Один Level Up повышает уровень ровно на 1 и сохраняет накопленный XP, даже если его достаточно для нескольких уровней.
- Добавлены независимые `masteryPendingFragments` и `petPendingFragments` с ручным Collect в единый spendable баланс Fragments.
- Прогресс Искусств начисляет награды в Mastery pending, а фактически применённый Pet Level Up начисляет награду в Pet pending.
- Collect выполняется на сервере по источнику, не принимает сумму от клиента и безопасен при повторных/stale запросах.
- Reset нового цикла очищает Fragments, Mastery pending и Pet pending без автоматического claim.

## Совместимость

- Сохранён один spendable баланс Fragments на базе существующего `runBranchCurrency`; отдельный дублирующий баланс не вводится.
- Для миграции Pet XP из v2.4.0 добавлен persisted baseline `appliedLevelXp`, сохраняющий прежние Level/XP без разрушительного пересчёта.
- Awakening, cooldown, Rank Revert, Advanced+ persistence и `PET_XP_MULTIPLIER` сохраняют прежний контракт.
- UI-терминология бывшего Prestige переведена на «Искусства», техническая новая терминология использует Mastery без рискованного массового переименования legacy-классов.

## Balance Core

- Награда за Pet Level Up управляется Balance Core.
- XP thresholds и награды Mastery остаются data-driven.

## Проверки

- Добавлены и обновлены regression-тесты для ручного Level Up, накопления XP за несколько уровней, pending Fragments, Collect, reset, миграции и существующих Pet regressions.
