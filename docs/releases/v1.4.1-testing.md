# v1.4.1 test coverage

The Balance Core uses JUnit tests mirrored under `src/test/java/com/example/revolution/balance`.

Coverage includes:

- numeric and string JSON decimal input;
- malformed JSON structure rejection;
- unsupported curve modes;
- unsupported schema versions;
- invalid curve ids;
- negative values;
- empty tables;
- invalid PIECEWISE coverage;
- all four curve modes;
- PIECEWISE local index behavior;
- values beyond primitive integer ranges;
- deterministic semantic SHA-256 revisions;
- prepare-vs-activate behavior;
- rollback-by-non-activation when validation fails.
