# RE:volution Mod v2.0.1

## Назначение релиза

`v2.0.1` — точечный хотфикс звука managed-мобов для ZBT-версии 2.0.

## Исправлено

- Managed-мобы RE:volution больше не воспроизводят стандартные звуки базовых Zombie и Skeleton: окружающие, получение урона и смерть.
- Обычные мобы Minecraft, которыми не управляет RE:volution, не изменены.

## Что не меняется

- World, Mongo schema и Balance Core schema version не меняются.
- Баланс, награды, HP, движение и внешний вид managed-мобов не меняются.
- Клиентский интерфейс и resource pack не меняются.
