# RE:volution Mod v2.3.1

## Исправлено

- Prestige reset для Rune Enhancement теперь применяет селективный wipe по фактическому рангу руны до сброса.
- Для рангов ниже `ADVANCED` сбрасываются и ранг, и уровень усиления.
- Для `ADVANCED` и всех более высоких рангов сохраняются и ранг, и уровень усиления.
- Добавлен точечный reset усиления одной руны, чтобы Prestige не затрагивал усиления других рун в коллекции.

## Регрессии

- Rune Rank Revert по-прежнему сохраняет усиление.
- Обычный rank-up по-прежнему сохраняет усиление.
- Безлимитное усиление после +50 не изменено.
- Permanent unlock коллекций не откатывается.
- Pets, Balance Core, GUI и остальные системы вне области этого patch-релиза не изменялись.

## Проверка

Покрыты кейсы Ordinary, Improved, Advanced, Mythic, будущий ранг выше Advanced и отсутствующая руна. Политика остаётся generic: любой ранг `>= ADVANCED` использует preserve, любой существующий ранг `< ADVANCED` использует reset.
