# RE:volution v2.6.0

## Основное

- Run Exchange переведён из foundation в рабочую server-authoritative систему с 7 baseline offers.
- Доступны: Pet Slot за Fragments, а также Coins, Rune Dust и Shards за Fragments или Crystals.
- Cores, Forge/Artifact resources и premium Pet Slot offers в этот релиз не входят.

## Экономика Run Exchange

- Для Coins, Rune Dust и Shards награда считается как процент от фактического текущего баланса целевого ресурса непосредственно перед применением покупки.
- У каждого из 6 resource-offers свой независимый run-scoped purchase counter.
- Стоимость повторных покупок рассчитывается через Balance Core по factual purchase index конкретного offer.
- Pet Slot не получает отдельный Exchange counter и продолжает использовать canonical Pet Slot counter/cost path.
- Fragments списываются из активного `runBranchCurrency`; Crystals используют canonical ResourceService storage.
- Exchange grants идут через non-earned grant path и не создают искусственный Mastery progress.

## Server authority и persistence

- Клиент передаёт только `offerId + expectedRunId`; сервер сам определяет cost, purchase index, factual balance, reward percent и итоговую reward amount.
- Stale run и insufficient-currency запросы не изменяют counters или балансы.
- Resource-offer counters сохраняются внутри активного run в `runExchange.purchases`.
- Persistence schema остаётся `3`: старые v2.5 saves без этого поля загружаются с нулевыми counters и корректно переписываются при следующем save.
- Новый run получает пустые Exchange counters; Crystals остаются вне run state и не сбрасываются вместе с run.

## Balance Core

- Добавлен bundled overlay `v2.6.0-run-exchange.json`.
- Offer enable/payment/target/unlock policies, cost curves и reward-percent curves data-driven и не зашиты в Java core logic.
- Утверждённых production ZBT-чисел в handoff нет, поэтому bundled значения явно имеют статус `run_exchange.zbt_status=draft`.
- Технические draft values для функционального тестирования: Fragment cost base `1`, Crystal cost base `10`, growth `1.35`, reward `10%`.

## Проверки

- Добавлены regression-тесты точного 7-offer catalog, currency mapping, factual percentage rewards, repeat purchases, increasing costs, independent counters, Crystal/Fragment charging, zero target balance, stale/insufficient rejection, canonical Pet Slot integration и Mastery isolation.
- Добавлен persistence migration regression для старого active-run документа без `runExchange`.
- Release CI проходит Java 8 build/tests, architecture/resource guards и packaged classes/resources verification.
