# Custom GUI Mod v1.1.7

Восстановлено пробуждение рун нажатием колёсика после выделения `GuiLayout`:

- обработчик среднего клика использует текущую раскладку через типизированный метод экрана;
- удалены reflection к старым полям `CardsGuiScreen` и дублирующий расчёт сетки;
- сохранены ограничения первого статуса, заполненной коллекции, поиска и максимального ранга;
- добавлены регрессии выбора всех 26 рун, масштабирования, границ слотов и состояний коллекции;
- публикация релиза требует подготовленного непустого файла описания;
- работа пробуждения подтверждена пользователем в Minecraft.

Причина регрессии: обработчик среднего клика читал поля сетки, перенесённые в `GuiLayout`. Клиентский журнал подтвердил `NoSuchFieldException`; исправление устранило эту зависимость. Серверные правила рангов и расходования коллекции сохранены.
