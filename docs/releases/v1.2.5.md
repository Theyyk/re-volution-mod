# v1.2.5 — основа прогрессии рун

Версия v1.2.5 формирует единый фундамент прогрессии рун: ранги, правила пробуждения, серверные проверки и отображение состояния в интерфейсе теперь используют одну модель.

## Изменения

- Поддерживаются три ранга рун: **Обычная → Улучшенная → Продвинутая**.
- Правила перехода между рангами вынесены в общий API прогрессии.
- Решение о возможности пробуждения теперь возвращает конкретную причину отказа: неполная коллекция, отсутствующая руна, максимальный ранг или коллекция, которая ещё не готова к следующему этапу.
- Клиентская доступность пробуждения выровнена с серверной проверкой.
- Сервер больше не дублирует собственную логику рангов и использует общий механизм прогрессии.
- В tooltip руны показывается её ранг.
- Для рангов используются визуальные маркеры: у обычной руны маркера нет, у улучшенной — белый, у продвинутой — золотой.
- В блоках валюты и ресурсов рун добавлены компактные иконки; такая же иконка используется рядом с ценой покупки.
- Интерфейс рун предзагружает коллекцию, активную вкладку и статистику игрока до показа экрана, поэтому промежуточное состояние покупки больше не должно появляться при открытии.
- После покупки кнопка больше не переходит во временное состояние `Загрузка...`.
- Цена на кнопке покупки формируется до отрисовки кадра, поэтому при серии покупок значение не дёргается между промежуточными состояниями.
- Исправлено наложение legacy-блока ресурсов на новые панели валюты и ресурсов рун.
- Исправлено затемнение/мерцание полупрозрачных панелей при наведении на руны.
- Подсказка действия `Пробудить` теперь показывает левую кнопку мыши.

## Прогрессия

Пробуждение остаётся коллекционной механикой:

- выбранная руна повышается на следующий ранг;
- руны текущего ранга коллекции расходуются;
- уже полученные руны более высокого ранга сохраняются;
- при наличии рун более низкого ранга нельзя перескочить на следующий этап;
- продвинутый ранг является максимальным.

Сетевое действие `upgrade_rune:` сохранено для совместимости, но по-прежнему означает **пробуждение**, а не отдельную механику улучшения.

## Экономика

Платное пробуждение в v1.2.5 **не включено**. Настраиваемая покупка рун и компенсация за дубликаты из v1.2.4 продолжают работать без изменения своей модели.

## Проверка

Runtime-проверка пройдена для предзагрузки GUI, повторных покупок, стабильной цены на кнопке, tooltip и маркеров рангов, панелей ресурсов, ограничения коллекции 26/26 и поведения пробуждения.

CI feature-ветки, develop и main также пройден до подготовки релиза.
