## Changes

- GuiLayout owns the logical 1280x669 canvas, viewport scaling, panel/grid/navigation bounds, purchase animation origin, rune slot coordinates and pointer conversion. CardsGuiScreen delegates these calculations and reads the same geometry for drawing and hit testing.
- GuiTheme owns all 45 named/inline palette values used by the screen and controls; values are unchanged. Control IDs stay with GuiControls, and geometry stays separate from colors.
- Removed unused legacy GUI/main bounds and limits, which had no readers.
- Version metadata and build instructions advance to 1.1.6. Screenshots remain labelled v1.1.4.

Gameplay, inventory, search matching, amount cycling, packet commands, server/Mongo code, fonts, textures, shader and shader ownership are unchanged. Surface drawing and font rendering remain the v1.1.5 implementations.
