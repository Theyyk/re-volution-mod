# v1.3.12 Location Generation Foundation

## Scope

v1.3.12 introduces the first deterministic Location provisioning layer. It creates a configured empty stage around an admin player and prepares a reproducible generation plan for future construction templates.

This version does **not** place Minecraft blocks or build structures yet. Real construction templates are not available yet, so world mutation remains a future adapter concern.

## Admin command

```text
/location create <locationId> <mobSlotId> [seed]
```

The command:

- creates a new `MOB_ZONE` stage at the executing player's current position;
- uses the default stage template radius;
- persists stage geometry through the existing `LocationRepository`;
- leaves mob population empty so admins can populate it separately;
- refreshes managed stage topology immediately without a server restart;
- rejects duplicate stages;
- rejects stages created after an existing Boss Zone in the same Location;
- accepts an optional explicit signed 64-bit seed.

When no seed is supplied, a deterministic seed is derived from the Minecraft world seed, Location/stage ids and the player's block anchor.

## Architecture

`LocationTemplate` describes static template constraints and allowed decoration families. `LocationGenerationPlanner` is a pure deterministic planner with no Minecraft or persistence dependency. `LocationGenerationPlan` contains the selected rotation and future decoration placements. `LocationProvisioningService` persists only stage geometry and keeps Minecraft world mutation outside the application layer.

The current default template exposes future variation points for:

- flower clearings;
- tree clusters;
- rock clusters;
- 90-degree stage rotation;
- independent decoration rotation.

A later world-generation adapter can map these planned placements to actual REBuilder/templates or block operations without changing the deterministic planning contract.

## Non-goals

Not included in this foundation:

- automatic block/structure placement;
- random terrain sculpting;
- mob population;
- boss assignment;
- automatic transition-point placement;
- final visual template assets.
