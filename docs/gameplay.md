# Игровые системы и интерфейс

## ✨ Руны и интерфейс

Интерфейс открывается клавишей `C`.

Основная компоновка:

- слева находятся компактные блоки **Статистика** и **Ресурсы**;
- по центру отображается персонаж и каркас будущей системы снаряжения;
- справа находится инвентарь рун;
- над рунами расположен селектор статусов;
- крайняя правая панель содержит вкладку рун и кнопку закрытия интерфейса.

Первый статус содержит **26 фиксированных позиций**. Каждая позиция представляет отдельную руну и хранит собственное состояние независимо от других позиций, даже если несколько позиций используют одинаковую иконку.

### Статус Яд

Текущий набор содержит 11 уникальных рун:

| Руна | Тип |
|---|---|
| Кинжал убийцы | Клик |
| Накидка убийцы | Клик |
| Перчатка скрытого удара | Клик |
| Камень заточки | Клик |
| Амулет ярости | Клик |
| Токсичный осколок | Клик / Яд |
| Клык змеи | Яд |
| Печать заражения | Яд |
| Усилитель токсина | Яд |
| Метка заражения | Яд |
| Реликвия охотника | Ресурс |

Текстуры находятся не внутри JAR мода, а в отдельном наборе ресурсов и подключаются через то же пространство имён `customguimod`. Мод хранит `ResourceLocation`, игровую логику и состояние, а набор ресурсов отвечает за PNG.

### Покупка рун

Покупка поддерживает режимы:

```text
x1
x5
x10
x100
```

Полученные руны занимают свои заранее определённые позиции каталога. Покупаемая руна всегда начинает с базового ранга.

### Пробуждение

Ранги идут по цепочке **Обычная → Улучшенная → Продвинутая**. Следующий этап пробуждения открывается только после того, как вся коллекция достигла требуемого минимального ранга.

GUI разделяет два состояния:

- постоянная рамка показывает уже достигнутый ранг: Improved — серебряная, Advanced — золотая;
- мерцающий значок слева появляется только у рун, которые можно пробудить прямо сейчас с учётом progression-gating и доступного баланса ресурса пробуждения.

После пробуждения одной руны значок для уже повышенного слота исчезает, а остальные минимальные по рангу слоты продолжают показывать доступность следующего действия. На Advanced значок больше не отображается.

### Усиление

Усиление — отдельная от пробуждения механика. Каждый из 26 фиксированных слотов хранит собственный постоянный уровень `+N`.

Селектор усиления поддерживает:

```text
x1
x5
x10
x100
```

Каждая попытка независимо выбирает один из 26 фиксированных слотов. Повторные попадания в один и тот же слот разрешены. Усиление принадлежит позиции, поэтому может сохраниться даже у пустого слота и начать влиять на руну после её получения.

Текущая формула v1.2.9:

```text
finalPower = basePower × (1 + enhancementLevel × enhancementStep)
enhancementStep = 0.1
```

Это линейное усиление: `+10` даёт множитель `×2`, `+100` — `×11`. Усиление не меняет ранг и не заменяет пробуждение.

Текущий технический расход усиления — фиксированная Пыль рун за каждую попытку; финальный баланс экономики будет настраиваться отдельно в следующих версиях.

### Визуальная обратная связь

- покупка/дубликат — короткая синяя вспышка;
- усиление — короткая зелёная вспышка;
- Improved — спокойная светло-серебряная рамка;
- Advanced — спокойная светло-золотая рамка;
- доступное и оплачиваемое пробуждение — мерцающий серебряный или золотой значок слева.

Tooltip руны в текущем v1.2.9 показывает имя, ранг, тип, `Улучшение: +N` и итоговые значения тех эффектов, которые уже подключены к stat framework. Расширение полного набора статусов и отображаемых статов вынесено в следующую версию.

### Адаптивность

Интерфейс масштабируется под разные размеры окна, сохраняя основную структуру и доступность элементов управления.

## ⚔️ Бонус урона

Существующая игровая механика сохраняет бонус урона от сохранённых рун/прежних карточек.

Сервер суммирует сохранённые записи игрока и применяет бонус через Forge-событие урона.

Кастомные мобы не используют ванильную броню, поэтому итоговый урон соответствует серверному расчёту.

В интерфейсе строка `Урон за клик` отображает существующее значение бонуса урона. Отдельная полноценная статистика кликов и типов урона запланирована на дальнейшие версии.

## 👾 Кастомные мобы

Поддерживаются:

- зомби (`Zombie`);
- скелеты (`Skeleton`).

Для каждого моба настраиваются имя, ресурс награды, количество ресурса, максимальное здоровье, тип и точка спавна.

Мобы:

- не используют ИИ;
- не перемещаются;
- имеют фиксированную точку спавна;
- быстро возрождаются после смерти;
- не выбрасывают ванильный дроп;
- защищены от лавы, огня, TNT и других внешних источников урона;
- получают урон от игрока.

Над каждым мобом отображаются имя, текущее здоровье, максимальное здоровье и награда.

## 💎 Система ресурсов

Каталог ресурсов фиксирован и разделён на валюту и ресурсы рун.

**Валюта:**

```text
coins
crystals
```

**Ресурсы рун:**

```text
rune_dust
rune_shards
rune_cores
```

Иерархия ресурсов рун: **Пыль рун → Осколки рун → Ядра рун**.

Создание и удаление пользовательских ресурсов во время работы сервера не поддерживается. `/customresource` оставлен только для просмотра фиксированного списка и баланса. Старое `lightnings` выведено из системы и очищается из исторических данных при миграции.

Игровые действия с ресурсами используют общий серверный контракт: проверка достаточности, безопасное списание без отрицательного баланса и выдача ресурса. Каждому кастомному мобу при создании назначается один из фиксированных действующих ресурсов и его количество. Для старых мобов без сохранённого поля ресурса сохраняется совместимость с монетной наградой.
