# Игровые системы и интерфейс

## ✨ Руны и интерфейс

Интерфейс открывается клавишей `C`.

Основная компоновка:

- слева находятся компактные блоки **Статистика** и **Ресурсы**;
- по центру отображается персонаж и каркас будущей системы снаряжения;
- справа находится инвентарь рун;
- над рунами расположен селектор статусов;
- крайняя правая панель содержит вкладку рун и кнопку закрытия интерфейса.

Первый статус содержит **26 фиксированных позиций**. Каждая позиция представляет отдельную руну и хранит собственное состояние независимо от других позиций, даже если несколько позиций используют одинаковую иконку.

### Статус Яд

Текущий набор содержит 11 уникальных рун:

| Руна | Тип |
|---|---|
| Кинжал убийцы | Клик |
| Накидка убийцы | Клик |
| Перчатка скрытого удара | Клик |
| Камень заточки | Клик |
| Амулет ярости | Клик |
| Токсичный осколок | Клик / Яд |
| Клык змеи | Яд |
| Печать заражения | Яд |
| Усилитель токсина | Яд |
| Метка заражения | Яд |
| Реликвия охотника | Ресурс |

Текстуры находятся не внутри JAR мода, а в отдельном наборе ресурсов и подключаются через то же пространство имён `customguimod`. Мод хранит `ResourceLocation`, игровую логику и состояние, а набор ресурсов отвечает за PNG.


### Покупка рун

Покупка поддерживает режимы:

```text
x1
x5
x10
x100
```

Полученные руны занимают свои заранее определённые позиции каталога. Покупаемая руна всегда начинает с базового ранга.

### Адаптивность

Интерфейс масштабируется под разные размеры окна, сохраняя основную структуру и доступность элементов управления.

## ⚔️ Бонус урона

Существующая игровая механика сохраняет бонус урона от сохранённых рун/прежних карточек.

Сервер суммирует сохранённые записи игрока и применяет бонус через Forge-событие урона.

Кастомные мобы не используют ванильную броню, поэтому итоговый урон соответствует серверному расчёту.

В интерфейсе строка `Урон за клик` отображает существующее значение бонуса урона. Отдельная полноценная статистика кликов и типов урона запланирована на дальнейшие версии.

## 👾 Кастомные мобы

Поддерживаются:

- зомби (`Zombie`);
- скелеты (`Skeleton`).

Для каждого моба настраиваются имя, ресурс награды, количество ресурса, максимальное здоровье, тип и точка спавна.

Мобы:

- не используют ИИ;
- не перемещаются;
- имеют фиксированную точку спавна;
- быстро возрождаются после смерти;
- не выбрасывают ванильный дроп;
- защищены от лавы, огня, TNT и других внешних источников урона;
- получают урон от игрока.

Над каждым мобом отображаются имя, текущее здоровье, максимальное здоровье и награда.

## 💎 Система ресурсов

Встроенные ресурсы:

```text
coins
crystals
lightnings
```

Дополнительные ресурсы можно создавать через `/customresource`.

Каждому кастомному мобу при создании назначается конкретный ресурс и его количество. Для старых мобов без сохранённого поля ресурса используется совместимость с прежней монетной наградой.
