# v2.4.1 release invariant

The stable v2.4.1 tree must keep all release metadata aligned to `2.4.1` before the tag is published:

- `build.gradle` project version;
- `src/main/resources/mcmod.info` version;
- `RevolutionMod.VERSION`;
- README stable version and current release contract link;
- Russian and English v2.4.1 release descriptions.

The gameplay contract remains Manual Pet Level Up, independent Mastery/Pet pending Fragments, source-specific Collect into the single spendable Fragments balance, and safe v2.4.0 Pet XP migration.
