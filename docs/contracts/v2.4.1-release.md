# RE:volution v2.4.1 release contract

Release: `v2.4.1`

This patch preserves the v2.4.0 Pet System contracts while changing Pet XP and Fragment claim semantics:

- Pet XP accrues online without automatic level application.
- One Pet Level Up action applies exactly one level and preserves banked XP.
- Applied Pet Level Up rewards `petPendingFragments`; reaching an XP threshold alone does not reward Fragments.
- Mastery progression rewards `masteryPendingFragments`.
- `runBranchCurrency` remains the single persisted spendable Fragments balance for the active run.
- PET and MASTERY Collect are source-specific, server-authoritative and stale-run guarded.
- Mastery reset / branch switch clears spendable Fragments and both pending pools without auto-claim.
- v2.4.0 Pet level/XP data loads without destructive recalculation; v2.4.1 tracks applied manual thresholds separately.
- Advanced+ Pet progression, Awakening, cooldown, rank revert and `PET_XP_MULTIPLIER` behavior remain compatible.
- `AUTO_PET_LEVEL_UP` and `AUTO_FRAGMENT_COLLECT` are not unlocked in v2.4.1; future automation must reuse the same authoritative services.
