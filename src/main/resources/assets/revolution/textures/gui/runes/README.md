# Poison status rune icons

Place the eleven final PNGs in this directory (exact lowercase names):

- killer_dagger.png
- killer_cloak.png
- hidden_strike_glove.png
- sharpening_stone.png
- rage_amulet.png
- toxic_shard.png
- snake_fang.png
- infection_seal.png
- toxin_booster.png
- infection_mark.png
- hunter_relic.png

Recommended: transparent 128 x 128 canvases, objects centered at a consistent scale
and with matching transparent margins. The renderer fits the full canvas, preserving
its aspect ratio, into a padded area while the separate type badge is drawn on top.
Non-square PNGs are supported. Missing/invalid files show a neutral framed placeholder.
Reopen the screen after reloading resources to refresh cached dimensions/missing-file
results. Repeated catalog positions share texture paths, but retain separate ownership
and ranks. No generated artwork is included. Other statuses retain their existing item
icons until their own PNG sets are added.
