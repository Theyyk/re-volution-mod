GUI typography references
=========================

These font files were supplied from the user's installed Cristalix Minigames
client, `libraries/mcassets.jar`:

- `assets/minecraft/fonts/minecraft_seven.crifont` -> `font.otf`:
  MinecraftSevenv2-Regular, used for body text, values, controls and tooltips.
- `assets/minecraft/fonts/minecraft_five.crifont` -> `font.otf`:
  MinecraftFivev2-Regular, used for uppercase section headings.

The files are preserved byte-for-byte. They are loaded only by the custom GUI;
they do not replace Minecraft's global font or require Cristalix to be installed
on the machine running the mod. Original font metadata remains embedded in OTF.

Permission scope and unchanged support screenshot: see docs/permissions/cristalix.md in the repository. Third-party font rights are not replaced by the repository LICENSE.
