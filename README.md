# Custom GUI Mod — Forge 1.12.2

Портфолио-проект игрового режима для Minecraft 1.12.2 с кастомным GUI, системой рун и статусов, кастомными мобами, ресурсами и хранением данных в MongoDB.

Проект построен на Forge Dedicated Server и использует единый клиент-серверный мод. Чисто визуальные PNG-ассеты рун вынесены в отдельный [RE:volution Resource Pack](https://github.com/Theyyk/re-volution-resource-pack).

**Текущая версия: `v1.1.7`**

---

## 🎯 Что реализовано

- переработанный адаптивный GUI в стиле игрового инвентаря;
- система рун с **26 фиксированными позициями** для первого статуса;
- независимое состояние каждой позиции руны;
- первый статус **Яд** с отдельным набором из 11 уникальных rune-иконок;
- типы рун `Клик`, `Яд`, `Клик / Яд`, `Ресурс`;
- ранги отдельных позиций рун;
- покупка рун `x1`, `x5`, `x10`, `x100`;
- временный технический лимит покупки в 26 рун для текущей коллекции;
- блоки статистики и ресурсов игрока;
- предпросмотр персонажа и каркас будущей системы снаряжения;
- компактная правая навигационная панель с вкладкой рун и кнопкой закрытия;
- бонус урона от сохранённых рун/legacy-карточек;
- постоянный HUD: монеты, кристаллы и общий бонус урона;
- кастомные Zombie и Skeleton;
- собственные HP-полоски над мобами;
- разные ресурсы-награды для разных мобов;
- создание пользовательских ресурсов через команды;
- быстрое возрождение кастомных мобов;
- отключение ванильного дропа;
- защита кастомных мобов от внешних источников урона;
- MongoDB-хранение игроков, наборов, рун, мобов и ресурсов;
- настраиваемые URI и имя MongoDB через JVM properties;
- Tab-автодополнение команд с фильтрацией по введённому префиксу;
- регрессионные тесты для каталога рун и инвентаря;
- предзагрузка rune-текстур при инициализации клиента без декодирования PNG во время GUI-рендера.

## ✨ Руны и GUI

GUI открывается клавишей `C`.

Основная компоновка:

- слева находятся компактные блоки **Статистика** и **Ресурсы**;
- по центру отображается персонаж и каркас будущей системы снаряжения;
- справа находится инвентарь рун;
- над рунами расположен селектор статусов;
- крайняя правая панель содержит вкладку рун и кнопку закрытия GUI.

Первый статус содержит **26 фиксированных позиций**. Каждая позиция представляет отдельную руну и хранит собственное состояние независимо от других позиций, даже если несколько позиций используют одинаковую rune-иконку.

### Статус Яд

Текущий набор содержит 11 уникальных рун:

| Руна | Тип |
|---|---|
| Кинжал убийцы | Клик |
| Накидка убийцы | Клик |
| Перчатка скрытого удара | Клик |
| Камень заточки | Клик |
| Амулет ярости | Клик |
| Токсичный осколок | Клик / Яд |
| Клык змеи | Яд |
| Печать заражения | Яд |
| Усилитель токсина | Яд |
| Метка заражения | Яд |
| Реликвия охотника | Ресурс |

Текстуры находятся не внутри JAR мода, а в отдельном resource pack и подключаются через тот же namespace `customguimod`. Мод хранит `ResourceLocation`, игровую логику и состояние, а resource pack отвечает за PNG.

![Актуальный GUI v1.1.4](screenshots/gui-v1.1.4-full.png)

### Покупка рун

Покупка поддерживает режимы:

```text
x1
x5
x10
x100
```

Полученные руны занимают свои заранее определённые позиции каталога. Покупаемая руна всегда начинает с базового ранга.

### Адаптивность

GUI масштабируется под разные размеры окна, сохраняя основную структуру и доступность элементов управления.

## 🧩 Resource pack

В `v1.1.2` rune-artwork вынесен из мода в отдельный репозиторий:

[Theyyk/re-volution-resource-pack](https://github.com/Theyyk/re-volution-resource-pack)

Разделение ответственности:

```text
re-volution-mod
├─ Java-логика
├─ GUI-логика
├─ состояние игрока
├─ сеть
├─ MongoDB
└─ ResourceLocation
        ↓
re-volution-resource-pack
└─ PNG-текстуры
```

Все rune-иконки нормализованы до `128x128`. Мод больше не использует `ImageIO.read` для определения размеров PNG во время рендера GUI. `RuneTexturePreloader` заранее прогревает уникальные rune-текстуры после загрузки ресурсов, поэтому первое открытие GUI не должно вызывать заметный фриз.

## ⚔️ Бонус урона

Существующая игровая механика сохраняет бонус урона от сохранённых рун/legacy-карточек.

Сервер суммирует сохранённые записи игрока и применяет бонус через Forge-событие урона.

Кастомные мобы не используют ванильную броню, поэтому итоговый урон соответствует серверному расчёту.

В GUI строка `Клики` пока использует существующее значение общего бонуса урона как временный показатель. Отдельная полноценная статистика кликов и типов урона запланирована на дальнейшие версии.

## 👾 Кастомные мобы

Поддерживаются:

- Zombie;
- Skeleton.

Для каждого моба настраиваются имя, ресурс награды, количество ресурса, максимальное HP, тип и точка спавна.

Мобы:

- не используют AI;
- не перемещаются;
- имеют фиксированную точку спавна;
- быстро возрождаются после смерти;
- не выбрасывают ванильный дроп;
- защищены от лавы, огня, TNT и других внешних источников урона;
- получают урон от игрока.

Над каждым мобом отображаются имя, текущее HP, максимальное HP и награда.

![Ресурсы мобов](screenshots/custom-mob-resources.png)

## 💎 Система ресурсов

Встроенные ресурсы:

```text
coins
crystals
lightnings
```

Дополнительные ресурсы можно создавать через `/customresource`.

Каждому кастомному мобу при создании назначается конкретный ресурс и его количество. Для старых мобов без сохранённого поля ресурса используется совместимость с прежней монетной наградой.

## 💻 Команды

Названия некоторых команд сохраняют legacy-терминологию для обратной совместимости.

### Мобы

```text
/custommob create <name> <resource> <amount> <hp> <type>
/custommob setspawn <name>
/custommob unspawn <name>
/custommob delete <name>
/custommob list
```

Поддерживаемые типы мобов:

```text
zombie
skeleton
```

### Ресурсы

```text
/customresource create <name>
/customresource delete <resource>
/customresource list
/customresource balance <resource>
```

### Legacy-колоды / наборы

```text
/customdeck create <name>
/customdeck switch <index>
/customdeck list
/customdeck delete <index>
```

Индексы начинаются с `0`.

### Руны / legacy-карточки

```text
/customcards clear
```

Для пользовательских команд реализовано Tab-автодополнение с учётом уже введённого префикса.

## 🗄️ MongoDB

Подключение конфигурируется JVM properties:

```text
-Dcustomguimod.mongo.uri=mongodb://localhost:27017
-Dcustomguimod.mongo.database=MyProject_build
```

Если свойства не заданы, используются эти значения по умолчанию.

Основные данные включают игроков, кастомных мобов и пользовательские ресурсы. Сервер остаётся источником истины для баланса, состояния рун, наград и игровой логики.

Для Build/Test окружения можно использовать разные имена баз без изменения исходного кода мода.

---

## 🌐 Клиент и сервер

```text
Forge Client
      ↕
SimpleNetworkWrapper
      ↕
Forge Dedicated Server
      ↕
MongoDB
```

Клиент отвечает в основном за GUI, HUD, рендер и ввод игрока.

Сервер является источником истины для баланса, рун, наборов, ресурсов, мобов, наград и расчёта урона.

---

## 🧪 Тесты

Регрессионные тесты проверяют, в частности:

- каталог из 26 фиксированных позиций;
- сохранение порядка каталога;
- независимость одинаковых рун в разных позициях;
- ранги отдельных позиций;
- соответствие rune-иконок;
- текущий лимит покупки;
- совместимость со старыми записями.

Тесты входят в `check` через задачу `runeInventoryRegression`.
